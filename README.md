# مزايد - Mazaid Platform

منصة عربية موحّدة للمزادات، الإعلانات، السيارات، العقارات، المتاجر، الخدمات والمحفظة الإلكترونية.

هذا المستودع يحتوي على الهيكل المبدئي للمشروع (skeleton) بالإضافة إلى وثيقة متطلبات المنتج (PRD) ووصول سريع لبدء التطوير.

رؤية سريعة
- تطبيق موحّد يجمع:
  - السيارات، العقارات، المتاجر، الخدمات، مزادات مباشرة، إعلانات مبوبة، ذكاء اصطناعي، محفظة/دفع إلكتروني، نظام توثيق.

نطاق الـMVP (المرحلة الأولى المبكرة)
- تسجيل/تسجيل دخول (OTP جوال + Google/Apple/بريد إلكتروني)
- ملف المستخدم والتوثيق البسيط
- قسم السيارات: إضافة إعلان، عرض إعلان، بحث أساسي
- مزاد مباشر للسيارات (real-time bids)
- محفظة داخلية وشحن عبر بوابة دفع (Stripe مبدئياً)
- دردشة بسيطة داخل التطبيق
- لوحة إدارة أساسية

تصميم وتجربة المستخدم
- هدفنا تصميم عصري وبسيط مناسب للجمهور العربي: واجهة RTL، أيقونات واضحة، ألوان دافئة (برتقالي/رمادي/أبيض)، وتباعد واضح للعناصر.
- سأجهز wireframes ونظام تصميم (design system) مبسط يتضمن: Palette ألوان، Typography، Buttons, Cards, Form inputs.

التشغيل المحلي
1) تثبيت Flutter: https://flutter.dev
2) استنساخ المستودع:
   git clone https://github.com/mzyzdm31-sys/mazaid-platform.git
3) الانتقال للمجلد وتشغيل التطبيق التجريبي:
   cd mazaid-platform/app
   flutter pub get
   flutter run

ملفات مهمة في المستودع
- PRD.md  — وثيقة المواصفات المبدئية
- app/ — هيكل مشروع Flutter (skeleton)
- firebase_setup.md — تعليمات إعداد Firebase (ملف placeholder — لا يتضمن مفاتيح)
- DESIGN/ — wireframes ومصادر التصميم (مضافة)

المراحل التالية التي سأقوم بها
- إضافة wireframes (صور أولية)
- إنشاء Issues تفصيلية لقصص المستخدمين في مستودع GitHub
- إعداد Firebase project skeleton (ملفات إعداد بدون مفاتيح)
